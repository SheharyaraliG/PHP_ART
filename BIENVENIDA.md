## TIPS RÁPIDOS

### Antes de comenzar:
- Instala XAMPP si no lo tienes
- Ten a mano phpMyAdmin (para la BD)
- Ten VS Code abierto para ver el código

### Mientras aprendes:
- Lee un archivo `.md` por vez
- Luego mira el código correspondiente
- Haz cambios pequeños y prueba
- Ejecuta comandos SQL en phpMyAdmin

### Después de instalar:

- Prueba crear, editar, eliminar obras
- Marca obras como favoritas

- Lee los comentarios del código
